## 🎯 About

A beautifully designed, fully responsive **multi-page website** for a cozy bookstore café. Features a warm color palette, interactive menus, book listings, events calendar, and contact page — all built with **pure HTML/CSS/JS**, no frameworks.

**Perfect for:** GitHub portfolio • Front-end showcase • Coffee shop/business website template
